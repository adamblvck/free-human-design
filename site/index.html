Free API

A slash and a query string

Every endpoint is a plain GET. CORS is open — call it from a browser, a notebook, or your AI.

EndpointReturns
/api/chartFull chart — Gene Keys + Human Design + Astrology
/api/genekeysGene Keys spheres only
/api/humandesignHuman Design bodygraph only
/api/astrologyAscendant / MC / houses (needs a location)
/api/promptA ready-to-paste AI interpretation prompt
/api/timezonesIANA timezone search (?q=bali)

Params: date=YYYY-MM-DD   time=HH:mm   tz=IANA   [lat lng house=placidus|whole|equal]
