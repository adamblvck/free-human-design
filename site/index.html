Use it online or offline

Two ways to use free-human-design — a free hosted REST API for quick online calls, or the npm package for fully local, private computation. Both return the same JSON.

EndpointReturns
/api/chartFull chart — hexagram profile + bodygraph + astrology
/api/hexagramsHexagram profile only
/api/bodygraphBodygraph only
/api/astrologyAscendant / MC / houses (needs a location)
/api/midpointsAdvanced — midpoint matrix over the 26 activations
/api/promptA ready-to-paste AI interpretation prompt
/api/timezonesIANA timezone search (?q=bali)

Params: date=YYYY-MM-DD   time=HH:mm   tz=IANA   [lat lng house=placidus|whole|equal midpoints=1]

Install the npm package and compute charts in pure JavaScript — no native build, no ephemeris files, your birth data never leaves your machine.

Install
npm install free-human-design
Usage
const { computeChart } = require('free-human-design');

const chart = computeChart({
  birthdate: '1972-08-02',
  birthtime: '14:30',
  timezone: 'Asia/Bangkok',
});

console.log(chart.bodygraph.type);                // "Manifesting Generator"
console.log(chart.bodygraph.profile);             // "3/5"
console.log(chart.hexagrams.p_sun.hexagram);   // 33
console.log(chart.astrology.angles.ascendant.sign); // "Sagittarius"
CLI
npx free-human-design --chart --date 1972-08-02 --time 14:30 --tz Asia/Bangkok

Questions

Frequently asked

Everything people ask before they cast their first chart.

Is there a free bodygraph API?

Yes — this is a free, open-source bodygraph API. One GET request to /api/bodygraph returns the full bodygraph: activated gates, defined channels, defined and open centers, Type, Authority and Profile. No API key, open CORS, MIT licensed.

Is there a free hexagram profile API?

Yes — /api/hexagrams returns the complete hexagram profile: the I-Ching hexagram and line for fourteen planetary placements. Free and open source.

How accurate are the calculations?

The engine is carefully tested: 259 passing tests across 13 suites (~90% coverage). Planetary positions come from the astronomia VSOP87 ephemeris and are validated to the exact gate.line against Swiss Ephemeris — including five real third-party charts (125/130 activations exact). A 2,000-birth deviation study against the reference engine shows 99.4% gate and 95.6% line agreement on profile placements. See the Accuracy section for the full breakdown.

Does my birth data stay private?

Yes. The engine is pure JavaScript and runs entirely on your machine — npm install free-human-design and nothing about your birth ever leaves your computer. The hosted API is stateless and stores nothing.

Can I use it with ChatGPT, Claude or another AI?

Yes — /api/prompt returns a ready-to-paste interpretation prompt containing your full chart, so any AI can read your bodygraph and hexagram profile and help you read it.

How do I install it?

npm install free-human-design, then computeChart({ birthdate, birthtime, timezone }) returns a hexagram profile, a bodygraph and astrology in one JSON. A CLI is included: npx free-human-design --chart --date 1972-08-02 --time 14:30 --tz Asia/Bangkok.
